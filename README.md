### 🏦 1. Prédiction du risque de crédit bancaire

**Objectif :** développer un modèle de Machine Learning capable d'estimer le risque de défaut de remboursement d'un emprunteur.

**Problématique :** comment exploiter les données financières et les caractéristiques des clients pour améliorer l'évaluation du risque de crédit ?

**Travaux envisagés :**
- Exploration et nettoyage des données de crédit.
- Analyse statistique et identification des variables pertinentes.
- Construction de modèles de classification.
- Évaluation avec précision, rappel, F1-score et ROC-AUC.
- Interprétation des résultats pour faciliter la prise de décision.

**Technologies :** Python, Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn.

🔗 **Dépôt :** [Voir le projet sur GitHub](https://github.com/TON-PSEUDO/credit-risk-prediction)
